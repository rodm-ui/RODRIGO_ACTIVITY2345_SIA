APPLICATION DEVELOPMENT

ACIVITY 1: Innovating the Future: Emerging Technology 
Application Design
Description : This performance task involves identifying a major emerging technology—Artificial Intelligence (AI)—and designing a conceptual mobile application named AgriSmart AI to address critical local challenges in Southern Leyte, Philippines. The concept focuses on empowering smallholder farmers to combat climate change, unpredictable weather, and crop diseases through AI-driven computer vision diagnostics and real-time insights. To maximize accuracy, the system integrates a supporting technology, the Internet of Things (IoT), establishing a smart, data-driven farming ecosystem. The final output includes a complete application framework, a localized community impact assessment, a system architecture diagram, and an in-depth academic reflection on the development process and required IT skill sets.
